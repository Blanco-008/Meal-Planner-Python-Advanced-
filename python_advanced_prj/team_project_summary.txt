SMART MEAL PLANNER - TEAM PROJECT SUMMARY

1. PROJECT OVERVIEW
This project is a smart meal planner application built using Python and Tkinter. It allows users to search for recipes, view detailed ingredients and instructions, add meals to a weekly plan, generate shopping lists, save favourite recipes, and use Gemini AI to simplify recipes and suggest substitutes.

The application combines several important parts of software development:
- user interface design,
- API integration,
- data handling,
- planning logic,
- and AI integration.

4. WHERE TO PLACE THE API KEY
The Gemini API key must be placed as an environment variable before running the app.
The code checks for either of these names:
- GEMINI_API_KEY
- GOOGLE_API_KEY

The key should not be hardcoded inside Python files.

On macOS/zsh, place it in the terminal like this:

export GEMINI_API_KEY="your_real_key_here"

Then start the app:

python main.py

If you want it to stay available every time you open a terminal, add it to your shell profile:

echo 'export GEMINI_API_KEY="your_real_key_here"' >> ~/.zshrc
source ~/.zshrc

5. IMPORTANT NOTE
The project is now configured so the Gemini library imports correctly, but the application still requires a valid Gemini API key in the environment to work successfully.

Without a real API key, the AI feature cannot call Google Gemini.
